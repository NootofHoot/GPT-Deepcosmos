# GPT-Deepcosmos
-What is GPT-Deepcosmos? 

GPT-DC is a open-source model built from the GPT 2 source code and modernized with modern libarys and archtecture such as swapping
tensorflow for pytorch and implementing RNS, MOE and more and featuring 8B parameters with a context of 1.75b parameters per token compared to GPT 2XL's 1.5B parameter model.
